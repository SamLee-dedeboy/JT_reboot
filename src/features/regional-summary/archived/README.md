# Archived Regional Summary prototype

This directory preserves the first regional summary prototype, including its map,
station-maximum view, threshold controls, tutorial, and methodology dialog.

The TypeScript source files use an `.archive` suffix so they remain intact without
being included in the application build. Remove that final suffix only when a
file is intentionally being restored for reference or reuse.

This prototype is historical source material rather than the specification for
the replacement interface. See the parent directory's `README.md` for the
current touchscreen interaction, planned exploration flow, and validation
requirements.
